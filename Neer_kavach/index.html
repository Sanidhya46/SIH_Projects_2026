Neer Kavach: Alternate Low-Cost Greywater Treatment for Flood-Prone & Space-Constrained Villages

An integrated, gravity-first decentralized greywater treatment pipeline combining physical screening, settling buffer, vertical multi-media biofiltration, automatic soak-pit overflow diversion, check-valve backflow flood armor, and zero-continuous-power local ESP32 Wi-Fi telemetry.

System Architecture Breakdown

Neer Kavach connects treatment, early fault detection, safe operating decisions, and community maintenance across 6 principal modules:

Module A: Pre-Treatment

Removable coarse screen (food scraps) + fine mesh (hair, lint) + dedicated kitchen grease trap.

Module B: Settling & Buffer

Sedimentation sump + 60L flow-surge buffer chamber with high-level alarm float switch.

Module C: Treatment Media

Stratified gravel, river sand, activated bio-char vertical column with rotary splash plate.

Module D: Flood Protection

External conductivity flood sensor + spring-loaded check valve + manual isolation shutoff.

Module E: Soak-Pit Manager

High-level reed switch + automatic diversion weir to secondary infiltration/storage holding.

Module F: Offline IoT Dashboard

ESP32 SoftAP web server (192.168.4.1), circular EEPROM event logs, zero SIM/cloud fees.
